# 従業員管理Webアプリ

架空の候補者を使って、選考管理と内定承諾後の従業員登録を試せるデモです。入力内容はブラウザの localStorage に保存します。実際の個人情報は入力しないでください。

## 起動

Node.js と npm を用意し、PowerShellで以下を実行します。

```powershell
npm.cmd ci
npm.cmd run dev
```

端末に表示されたローカルURLをブラウザで開きます。

「採用管理」で「見本 太郎」を開くと、内定承諾後に従業員登録へ引き継ぐ流れを試せます。

## 改修事例：従業員一覧の検索クリア

模擬チケット #42 として、従業員一覧に「検索をクリア」ボタンを追加しました。

変更したコードと確認結果は [Pull Request #2](https://github.com/pe-nabeya/employee-management-demo/pull/2) にまとめています。
