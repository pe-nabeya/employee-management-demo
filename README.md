# 従業員管理Webアプリ

架空の候補者を使って、選考管理と内定承諾後の従業員登録を試せるデモです。入力内容はブラウザの localStorage に保存します。実際の個人情報は入力しないでください。

## 起動

Node.js と npm を用意し、PowerShellで以下を実行します。

```powershell
npm.cmd ci
npm.cmd run dev
```

端末に表示されたローカルURLをブラウザで開きます。

「採用管理」で「見本 太郎」を開くと、内定承諾後に従業員登録へ引き継ぐ流れを試せます。

## 改修事例：従業員一覧の検索クリア

模擬チケット #42 として、従業員一覧に「検索をクリア」ボタンを追加しました。

Claude Codeで既存の検索処理を読み、ボタンを押すと検索欄だけが空になるように修正しました。Chromeで、検索をクリアしても選択した部署が残ることを確認し、型チェックも実施しました。

変更したコードと確認結果は [Pull Request #2](https://github.com/pe-nabeya/employee-management-demo/pull/2) にまとめています。

## 改修事例：全角・半角に対応した従業員検索

半角で登録した社員番号を、全角で入力しても検索できるように修正しました。

検索文字・社員番号・氏名・カナの4か所に `normalize('NFKC')` を追加しています。登録データ自体は変更しません。

### 確認したこと
- 半角「AB1001」の登録を、全角「ＡＢ１００１」で検索すると1件表示
- 存在しない番号では0件表示
- 検索クリア後も部署の絞り込みを保持
- 型チェック・ビルド成功

作業ブランチで修正し、diff確認・動作検証・PR作成・mainへのマージまで実施しました。

変更内容と確認結果：[Pull Request #3](https://github.com/pe-nabeya/employee-management-demo/pull/3)
